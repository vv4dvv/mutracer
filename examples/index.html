MuTracer 示例

  • 基础：程序化几何体、OpenPBR 材质、面光源与 HDR 环境。
  • Three.js：用 fromTHREEScene 转换带 glTF 模型的 Three.js 场景。
  • 动画：带骨骼动画和变形目标的程序化蒙皮圆柱。
  • 实例化：100 个共享立方体，通过矩阵编辑通知更新。
  • 焦散：聚光灯下的玻璃球；光线追踪需要 WebGPU。
  • 高级：OpenPBR 分层、阴影捕捉器、OIDN 降噪与离线 PNG 导出。

MuTracer 在可用时使用 WebGPU，否则回退到 WebGL 2。

需要交互式查看器（拖入 glTF 或 HDR、编辑材质、导出 PNG）？打开 viewer（本地运行 npm run viewer）。
